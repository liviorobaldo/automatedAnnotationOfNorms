<p>
This folder contains the source code and data for the research presented in the paper
<i>"Consistent template-based annotation of regulative norms from legislation with LLM support"</i>.
</p>

<p>The repository is organised into four folders:</p>

<br>
<h3>AnnotationToolAndGuidelines</h3>
<p>
This folder contains the JavaScript annotation tool used by the annotators hired for this research to manually construct the initial gold-standard corpus, together with the annotation guidelines describing how the annotation task was carried out.
</p>

<br>
<h3>Java</h3>
<p>
This folder contains Java procedures for pre-processing the gold-standard corpus (both the initial version manually annotated by experts and the subsequent versions produced via GPT-4.1 and manually validated), as well as post-processing scripts for the outputs returned by GPT-4.1.
</p>

<p><b>Pre-processing procedures:</b></p>
<ul>
  <li>
    Input: the gold-standard corpus.
    Output:
    <code>toFineTuneOpenAI_training.json</code> and
    <code>toFineTuneOpenAI_validation.json</code> (80% / 20% split),
    plus <code>batchForOpenAI.jsonl</code> for a new <code>&lt;part&gt;</code>code> of a UK Act.
  </li>
  <li>
    The first two files are used to fine-tune GPT-4.1, while the batch file is submitted to the fine-tuned model to automatically annotate new regulative norms.
  </li>
</ul>

<p><b>Post-processing procedures:</b></p>
<ul>
  <li>
    Input: GPT-4.1 outputs on <code>batchForOpenAI.jsonl</code>.
  </li>
  <li>
    Output: a JSON file that is added to the gold-standard corpus, subject to manual validation before inclusion.
  </li>
</ul>

<br>
<h3>Python</h3>
<p>
This folder contains scripts for fine-tuning GPT-4.1 and submitting batch requests for both Phase 1 and Phase 2 (see the paper for details). These scripts use the pre-processed files generated by the Java procedures.
</p>

<br>
<h3>CORPUS</h3>
<p>
This folder contains the datasets used and produced by the code in the other folders, including the original LegalDocML files (as available at the time of the research) and the corresponding JSON files with template-based annotations of regulative norms.
</p>
