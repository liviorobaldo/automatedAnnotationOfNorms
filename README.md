```text
This folder contains the source code and data for the research presented in the paper
"Consistent template-based annotation of regulative norms from legislation with LLM support".

The repository is organised into four folders:

- AnnotationToolAndGuidelines:
  This folder contains the JavaScript annotation tool used by the annotators hired for this research to manually construct the initial gold-standard corpus, together with the annotation guidelines describing how the annotation task was carried out.

- Java:
  This folder contains Java procedures for pre-processing the gold-standard corpus (both the initial version manually annotated by experts and the subsequent versions produced via GPT-4.1 and manually validated), as well as post-processing scripts for the outputs returned by GPT-4.1.

  In particular:
  - The pre-processing procedures take as input the gold-standard corpus and generate two files:
    `toFineTuneOpenAI_training.json` and `toFineTuneOpenAI_validation.json`, containing 80% and 20% of the samples respectively, as well as a file `batchForOpenAI.jsonl` constructed for a new `<part>` of a UK Act.
    The first two files are used to fine-tune GPT-4.1, while the latter is submitted to the fine-tuned model to automatically annotate new regulative norms.

  - The post-processing procedures take as input the output generated by GPT-4.1 on the file `batchForOpenAI.jsonl` and produce a new JSON file that can be added to the gold-standard corpus. This file still requires manual validation by annotators before being incorporated into the corpus.

- Python:
  This folder contains scripts for fine-tuning GPT-4.1 and for submitting batch requests, for both Phase 1 and Phase 2 (see the paper for further details). These scripts take as input the files pre-processed using the Java procedures described above.

- CORPUS:
  This folder contains the data used and produced by the code in the other folders. It includes the original LegalDocML files (note that publicly available versions are periodically updated, whereas the versions included here correspond to those available at the time this research was conducted), as well as the corresponding JSON files containing the template-based representations of regulative norms extracted from the LegalDocML documents.
```
